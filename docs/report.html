通報が入ったあとの流れ

  1. 仮非表示：通報が1件入った時点で、そのカードをすぐに仮非表示にします。最終的な削除ではありません。
  2. 運営の確認：運営が内容を確認し、問題がなければ表示に戻します。
  3. 削除の判断：削除する場合は、掲載した方への照会と、反論の機会を経てから判断します（情報流通プラットフォーム対処法の実務手順に沿います）。
  4. 繰り返しの通報：同じ通報元からの繰り返しの通報は、確認の際にその分を割り引いて判断します（嫌がらせ目的の通報への備えです）。
  5. 結果の扱い：確認の結果は、通報した方・掲載した方のどちらにも、必要以上の情報を出さない形で扱います（誰が通報したか、判定の内訳は出しません）。

申告フォーム（見本）

サービス内からの通報は、ログインした利用者だけが行えます（通報元を確認できるようにするためです）。

本番では、カード側のアカウントでログインします。利用者でない方（なりすましの被害に遭った方など）は、メール窓口から申告できます（アドレスは公開時に掲載します）。入口はこの2つだけです。

文章の入力欄はありません。理由は選択式だけです。詳しい事情が必要な場合は、運営から掲載した方・通報した方へ照会します。

いま仮非表示中のカード（この端末）

「戻す」は運営確認の見本です（この端末内だけの操作）。削除の判断は、上の流れのとおり照会と反論の機会を経て行うため、デモに削除ボタンは置いていません。
